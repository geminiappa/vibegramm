# Vibegram — обновлённый проект

В архиве лежит серверная веб-версия Vibegram без подтверждения Email и Windows Desktop оболочка.

## Что обновлено

- Адаптивный интерфейс чатов и каналов для компьютеров, планшетов и телефонов, включая safe-area для iPhone.
- SVG-иконки и SVG-стикеры, более плавные короткие переходы без повторной анимации всех сообщений при каждом цикле синхронизации.
- Аватарки профилей и каналов сохраняются на сервере; пустой локальный аватар с другого устройства не затирает сохранённую картинку.
- Синхронизация аватарки и полей профиля из серверного профиля при опросе API.
- Сервер игнорирует статусы `is_verified`, `is_premium` и `is_team`, переданные из браузера. Premium и отдельная звезда команды отображаются только при наличии серверной отметки выдачи; выбор SVG-эмодзи или изменение localStorage статусы не выдаёт.
- Выдача/снятие Premium и командной звезды через `@verify_bot` требует `VIBEGRAM_ADMIN_TOKEN` в Render. Админ-ключ не сохраняется в истории чата; без переменной окружения выдача заблокирована.
- Старые Premium/Team-флаги без истории серверной выдачи сбрасываются при миграции; такие статусы нужно выдать заново через администраторскую команду.
- Для вкладки сайта подключена иконка `facuicon.jpeg` (также присутствует алиас `favicon.jpeg`).
- Веб- и системные уведомления показывают аватар отправителя; при отсутствии картинки используется значок Vibegram. Клик по браузерному уведомлению возвращает в приложение и открывает нужный чат, если страница остаётся доступной. Windows Desktop передаёт аватар в нативное уведомление и рисует красный индикатор на значке в системном трее.
- В настройках профиля можно выбрать каналы для публичного профиля. Карточки каналов показывают название, @username, значки сервера, число подписчиков, последнюю публикацию и время. Выбор сохраняется сервером и синхронизируется между устройствами.
- Windows Desktop сворачивается в трей при закрытии окна; из меню трея можно восстановить окно, перезагрузить приложение, настроить автозапуск или выйти.

## Настройка защиты Premium и звезды команды

1. В Render → Environment добавь `VIBEGRAM_ADMIN_TOKEN` со случайным секретом не короче 32 символов. Не помещай этот секрет в HTML, GitHub, README или скриншоты.
2. После deploy отправляй боту команды, указывая секрет последним аргументом: `/premium @username on <ADMIN_TOKEN>`, `/premium @username off <ADMIN_TOKEN>`, `/team @username on <ADMIN_TOKEN>`, `/team @username off <ADMIN_TOKEN>`. Вместо `<ADMIN_TOKEN>` подставь значение переменной окружения. Само значение не сохраняется в истории сообщений.
3. Пользователи могут отправить `/premium request` или `/team request`, но не могут выдать статус без ключа.

## Деплой сайта на Render

1. Скопируй `server.py`, `index.html`, `service-worker.js`, `facuicon.jpeg`, `favicon.jpeg` и `requirements.txt` в корень репозитория.
2. Закоммить изменения и отправь в GitHub, подключённый к Render.
3. Проверь, что у Render команда запуска использует `python server.py`, а переменная `DATABASE_URL` остаётся прежней, если используется PostgreSQL.
4. Дождись завершения deploy и проверь https://vibegramm.onrender.com.

`server.py` сохраняет локальный JSON только если `DATABASE_URL` не задан. Для Render с PostgreSQL оставь существующую переменную окружения. На чистой установке ID 1 зарезервирован за создателем (`@paveldurov` или `@vibegram`); обычные новые аккаунты получают ID начиная с 1001.

## Windows Desktop

1. Установи Node.js 20 или новее.
2. Открой папку `VibegramDesktop`.
3. `config.json` уже указывает на `https://vibegramm.onrender.com`; при смене домена измени `appUrl`.
4. Выполни:

```powershell
npm install
npm start
```

Сборка установщика и portable EXE:

```powershell
npm run dist
```

Готовые файлы появятся в `VibegramDesktop/dist`. Сборка EXE требует Windows или подходящую среду Electron Builder; в этом архиве приложены исходники оболочки, а не заранее собранный EXE.

## Уведомления

Нажми на колокольчик рядом с названием Vibegram. В браузере нужно разрешить уведомления; Service Worker используется для отображения системного уведомления с аватаром и обработки клика. Windows Desktop передаёт аватар в нативное уведомление. Звук зависит от настроек ОС/браузера и громкости системы. Важно: сервер сейчас не рассылает Web Push с закрытой страницы — полная доставка при полностью закрытом браузере требует добавить VAPID-ключи и хранение push-подписок.

## Важное ограничение безопасности

Приложение использует текущую модель аккаунтов без пароля и полноценной серверной сессии. Поэтому это обновление закрывает обычную возможность самостоятельно выставлять галочку через поле профиля и проверяет одобрение на сервере, но не заменяет полноценную аутентификацию и защиту от подмены личности в API. Для публичного продакшена следующим этапом нужно добавить реальные серверные сессии/токены для аккаунтов и строгую роль создателя.

## Исправление окна описания галочки

- Окно описания значка (`badgeInfoModal`) имеет отдельный высокий `z-index` и всегда открывается поверх профиля, в том числе в Electron-приложении.
- Добавлена круглая кнопка закрытия с SVG-крестиком в правом верхнем углу.
- Закрытие доступно кнопкой «Понятно», крестиком, кликом по затемнённому фону и клавишей Escape.
- На телефонах учитываются safe-area отступы, окно адаптируется по ширине/высоте и поддерживает внутреннюю прокрутку.

Для установки замените `index.html` и выполните redeploy. Остальные файлы сервера менять не требуется.


## PWA для iPhone, Android и ПК

В архив добавлена установка Vibegram как веб-приложения (PWA): `manifest.webmanifest`, `pwa-192.png`, `pwa-512.png`, Apple mobile-web-app metadata и Service Worker. Установка на iPhone выполняется через Safari → «Поделиться» → «На экран Домой». На iOS/iPadOS для Web Push требуется iOS/iPadOS 16.4 или новее и запуск установленного приложения с домашнего экрана.

### Настройка настоящих push-уведомлений

Web Push требует VAPID key pair. После установки зависимостей локально сгенерируй ключи командой:

```powershell
python -m pip install -r requirements.txt
python scripts/generate_vapid_keys.py
```

Сгенерированная строка содержит `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT`. В Render → Environment добавь эти три переменные. **`VAPID_PRIVATE_KEY` — секрет; не публикуй его и не добавляй в HTML/GitHub.** Не перегенерируй ключи после появления подписок без необходимости, иначе существующие подписки придётся создать повторно.

После redeploy пользователи должны открыть Vibegram, войти в свой профиль, нажать колокольчик или открыть Профиль → Приложение Vibegram → «Включить push-уведомления» и разрешить уведомления. На iPhone сначала добавь сайт на домашний экран и запускай его с иконки. Профиль должен существовать на сервере. Подписки сохраняются в текущем хранилище JSON/PostgreSQL, а приватные подписки не передаются в `/api/sync`.

Сервер использует `pywebpush` и отдельные маршруты `/api/push/public-key`, `/api/push/subscribe`, `/api/push/unsubscribe`. При новых личных сообщениях push отправляется получателю; новые посты каналов — подписчикам канала, за исключением автора. Push-запросы выполняются в фоновых потоках, чтобы не задерживать HTTP-ответ отправки.

### Установка PWA

- iPhone/iPad: открыть сайт в Safari → «Поделиться» → «На экран Домой» → «Добавить»; затем открыть установленное приложение и включить push.
- Android/Chrome/desktop Chromium: нажать «Установить Vibegram», если браузер показывает доступный prompt; иначе использовать меню браузера «Установить приложение»/«Добавить на главный экран».

### Важное ограничение аутентификации

Текущий backend всё ещё использует username из клиентского запроса вместо полноценных серверных сессий/токенов. Поэтому Push-интеграция не исправляет старую проблему подмены личности в API. Перед публичным продакшеном необходимо добавить реальную аутентификацию и авторизацию push-подписок; не используй этот проект для конфиденциальных переписок, пока это не сделано.

## Прямая ссылка на установку для iPhone

После публикации этой версии на Render можно отправлять такую ссылку:

`https://vibegramm.onrender.com/?install=1`

По ней автоматически откроется красивое окно-инструкция по установке Vibegram. Важно: iOS не позволяет сайту самостоятельно открыть системное окно «На экран Домой» — пользователь должен вручную нажать «Поделиться» в Safari, выбрать «На экран Домой» и подтвердить добавление. Ссылка начнёт показывать эту инструкцию после публикации обновлённого `index.html` на Render.
